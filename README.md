[설치 - 최초 1회]
Python 3.10 이상이 필요합니다.
py -m pip install -r requirements.txt

[실행]
py -m streamlit run global_inventory_streamlit.py

브라우저가 자동으로 열리지 않으면 PowerShell에 표시되는 Local URL을 엽니다.

[기본 로직]
- 기준일: 기존 글로벌 시트 G1 우선, 없으면 파일명 날짜 기준 1~15일은 15일 / 16일 이후는 월말
- 잔여 유통기한 통과율: 66%
- 창고 순서: GD → DU → GL
- Product Master: '유효기간' 시트의 12행에 '바코드', '개봉 전 사용기한' 제목 필요
- 판토스 원본: 'Sheet1' 시트의 1행에 필수 열 제목 필요
- 창고별 상세 정렬: 제품별 → EXP 빠른 순 → 수량 적은 순 → LOT 오름차순
- 위 기준은 모두 웹 화면에서 변경할 수 있습니다.

[웹 화면 사용]
- 사이드바 옵션은 여러 항목을 연속으로 변경해도 즉시 재실행되지 않습니다.
- 변경을 마친 뒤 '옵션 적용'을 누르면 모든 설정이 한 번에 반영됩니다.
- 기준일 확인 체크와 '재고 파일 만들기'도 한 번에 제출되어 체크 시 별도 재실행이 발생하지 않습니다.
- 결과 다운로드 버튼은 앱을 다시 실행하지 않습니다.

[안전 검증]
- 기준일 확인 체크 후에만 생성할 수 있습니다.
- 가용재고 공란·문자·음수·소수, 잘못된 날짜, 빈 자재코드는 생성 전에 차단합니다.
- 실제 유통기한 공란과 마스터 사용기한 누락 재고는 설정에 따라 유지할 수 있습니다.
- 복수 LOT 문자열은 수량 배분 오류를 막기 위해 LOT별 행으로 분리하도록 안내합니다.
- 결과 파일의 피벗·창고별 상세 총수량을 자동 대사한 뒤 다운로드를 제공합니다.
- 파일당 최대 50MB, 원본 시트당 최대 200,000행까지 처리합니다.

[성능 최적화]
- 창고별 상세는 전체 데이터를 한 번만 순회해 집계합니다.
- 반복 셀 스타일 처리를 공용 NamedStyle로 통합했습니다.
- 동일 업로드 파일의 기존 기준일 조회 결과를 재사용합니다.
- 저장 전 수량 대사 후 저장된 파일은 구조·행 수·핵심 값만 빠르게 재검증합니다.
